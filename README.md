**Ofertas e descontos perto de você.**

Bem-vindo ao repositório do **Blog Caju Ofertas**. Este projeto é uma plataforma moderna e performática desenvolvida para entregar conteúdo relevante sobre ofertas, descontos e novidades, com foco em uma experiência de usuário excepcional.

## 🚀 Tecnologias

Este projeto foi construído utilizando as mais recentes tecnologias do ecossistema React:

- **[Next.js 16](https://nextjs.org/)**: Framework React para produção, utilizando App Router.
- **[React 19](https://react.dev/)**: Biblioteca para construção de interfaces de usuário.
- **[Tailwind CSS 4](https://tailwindcss.com/)**: Framework de utilitários CSS para estilização rápida e responsiva.
- **[TypeScript](https://www.typescriptlang.org/)**: Superset JavaScript tipado para maior segurança e manutenibilidade.
- **[MDX](https://mdxjs.com/)**: Conteúdo do blog gerenciado através de arquivos Markdown com JSX.
- **[Lucide React](https://lucide.dev/)**: Biblioteca de ícones leve e consistente.
- **[Next Themes](https://github.com/pacocoursey/next-themes)**: Suporte robusto para Dark/Light mode.
- **[Vercel Analytics](https://vercel.com/analytics)**: Métricas de privacidade em primeiro lugar.

## ✨ Funcionalidades

- **Blog Estático**: Geração de páginas estáticas (SSG) para máxima performance e SEO.
- **Modo Escuro**: Detecção automática de preferência do sistema e alternância manual.
- **SEO Otimizado**: Metatags completas, Open Graph e JSON-LD configurados.
- **Design Responsivo**: Layout fluido que se adapta a qualquer dispositivo, Mobile First.
- **Barra de Consentimento**: Conformidade com normas de privacidade (LGPD/GDPR).

## 🛠️ Instalação e Execução

Pré-requisitos: Node.js 20+ instalado.

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/shopmaior/caju-blog.git
    cd caju-blog
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    # ou
    yarn install
    # ou
    pnpm install
    # ou
    bun install
    ```

3.  **Execute o servidor de desenvolvimento:**

    ```bash
    npm run dev
    ```

    O projeto estará rodando em [http://localhost:3000](http://localhost:3000).

## 📂 Estrutura do Projeto

```
caju-blog/
├── app/              # Rotas e componentes do App Router (Next.js)
```
